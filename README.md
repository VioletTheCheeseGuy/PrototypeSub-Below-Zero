
# About this mod

The Prototype is a vehicle story mod for Subnautica which takes the player through new precursor facilities, new equipment and expands on the story of the Architects all while giving the player the ability to pilot and upgrade the highly advanced Prototype Submarine.

# How to install

  1.  Download the mod from this mod page
  2.  Unzip the file
  3.  Place the "PrototypeSubMod" folder inside your plugins folder
  4.  Example folder structure: 

    BepInEx/plugins/PrototypeSubMod



## NOTE:
You may notice a "TerrainPatches" folder inside the main mod folder. Please do not remove this folder from the main mod folder or move the files inside to the Terrain Patcher folder. Terrain patcher works for files not inside its patches folder so this is not necessary.

# Dependencies

    - Nautilus Zero (aka Nautilus Below Zero Release) - 1.0.49pre
    - Sub Library - Below Zero Port
    - Terrain Patcher - 1.2.4
    - Epic Structure Loader (unsure if it works on Below Zero)
    - Suit Library - Below Zero Port (Not to be confused with Sub Library)
